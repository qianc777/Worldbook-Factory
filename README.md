# 世界书工坊 · Worldbook Factory

在酒馆里直接选择、编辑和保存世界书，支持拖动排序、批量操作、重复条目清理预览和一键检查更新。

适配 **SillyTavern 1.17.0 及之后保持相同接口的版本**。使用酒馆自身的登录会话与世界书接口，无需 Extras、后端插件、API Key、Node 依赖或构建步骤。

## 通过 GitHub 安装

1. 打开酒馆 → 扩展 → 安装扩展。
2. 粘贴仓库地址：[https://github.com/qianc777/Worldbook-Factory](https://github.com/qianc777/Worldbook-Factory)。
3. 点击安装，完成后刷新酒馆。
4. 在原生世界书面板点击书本图标（悬停提示“打开世界书工坊”）；也可以从扩展设置的“打开工坊”或聊天框扩展菜单进入。

安装框接收上面的 GitHub 仓库地址，不接收 ZIP 或单独 HTML 文件。扩展不会自动打开、导入或修改任何世界书；只有点击“保存到酒馆”才会写入。

## 使用

- 首次打开是空白编辑器。在顶部“酒馆世界书”列表选择一本，点击“打开”。
- 编辑标题、关键词、正文、触发规则及高级字段后，点击“保存到酒馆”，或按 `Ctrl+S`。
- “新建世界书”会打开空白草稿，填写名称后可直接保存到酒馆。
- 修改已打开世界书的名称时，按钮会变成“另存为新世界书”。旧世界书及其角色绑定保留；不会自动改动角色卡的关联。
- 搜索、筛选、勾选多条后，可批量启用/禁用、设为常驻、设置插入优先级、添加关键词和删除。
- “清理重复条目”会扫描整本世界书，显示各组的保留项、待删除项及数量，确认后才从编辑草稿删除。点击“保存到酒馆”后才会写回酒馆。
- 正文重复以去除首尾空白、统一 CRLF 换行为 LF 后的文本判断。空正文按标题和主/次关键词判断。每组保留显示顺序最靠前的一条；触发规则不同但正文相同的条目也会被列出，请在预览中核对。
- 撤销/重做保留在本次编辑会话中。保存后也可以撤销，再保存一次恢复修改。
- JSON 导入/导出功能仍可用，用于离线备份和迁移。

### 列表宽度与条目移动

- 桌面端默认加宽条目列表。拖动列表与编辑区之间的分隔线即可调整宽度，双击恢复默认；宽度偏好保存在当前浏览器。分隔线也支持左右方向键及 Home/End。
- 在“显示顺序”下，拖动条目前的 `⠿` 手柄调整同一本书内的顺序。也可选中条目后点击上移、下移或“移动到…”，指定最终位置或移到最前/最后。
- 勾选多条后，这些操作会作用于勾选条目。成组拖动及指定位置移动会保留所选条目的相对顺序。
- 移动只改 `displayIndex`，不改 UID、正文或 `order`（提示词插入优先级）。原来的“设置顺序”批量操作调整的是插入优先级，与列表移动不同。
- 搜索、筛选或按其他字段排序时不允许移动。点击“清除筛选，恢复显示顺序”后再操作，避免隐藏条目导致位置不明确。
- 移动后可以撤销/重做；只有点击“保存到酒馆”才会写回。窄屏会采用上下布局，可用移动按钮完成排序。

## 保存与草稿

修改不会自动写回。收起编辑器后，本次页面中的草稿仍保留；关闭或刷新整个酒馆页面会丢失未保存草稿，并由浏览器提醒。浏览器是否弹出提醒取决于其自身策略。

保存前会重新读取世界书并与打开时的版本比较；发现其他页面已经修改时，停止写入并保留当前草稿。可先导出草稿，重新打开比较，或换名另存。保存后会再次读取核对并更新酒馆世界书缓存。酒馆接口本身没有原子版本锁，因此不要在多个页面同时保存同一本世界书。

编辑器会保留原有 UID、未知字段及顶层扩展数据。导入的文本按文本显示，不作为 HTML 执行。扩展没有内置世界书，也不包含任何用户数据。

## 更新

**从 v1.0.0 升级时：先在酒馆原生扩展管理里更新“世界书工坊”，并刷新酒馆页面一次，才能看到新版的更新按钮。**

此后，在工坊右上角或扩展设置卡片点击“检查更新”。若 GitHub 仓库有新提交，插件会使用酒馆自身的扩展更新接口自动下载，并显示结果；没有更新则提示已是最新版本。

下载不会自动刷新页面，也不会写入世界书。保存当前草稿后点击“刷新生效”，确认其他编辑也已保存后再刷新整个酒馆。有未保存的世界书草稿或正在保存时，会阻止刷新并提示处理。

更新仅接受本仓库 `qianc777/Worldbook-Factory` 的 Git 安装。全局安装需要管理员权限；无法连接 GitHub、非 Git 安装或本地改动导致更新失败时会显示错误，可使用酒馆原生扩展管理检查。不会强制重置或覆盖本地 Git 改动。本扩展不进行后台自动更新。

## v1.1.0 更新内容

- 世界书面板使用紧凑书本图标入口，扩展设置改为带版本和操作按钮的卡片。
- 工坊窗口和条目列表加宽，增加可拖动、可记忆的分栏。
- 支持同一本书内单条/多条拖动、上移/下移、移到指定位置及最前/最后。
- 新增检查更新、自动下载和受草稿保护的刷新按钮。

## 开发与验证

安装和使用不需要运行 npm。开发时可用 Node.js 18+ 执行 `npm test`，测试世界书读写、字段保留、重复清理后的恢复、冲突、同名保护、排序及更新成功/失败行为。

发布时，`manifest.json`、`index.js` 和 `style.css` 必须直接位于仓库根目录，`editor/` 与 `tests/` 保持目录结构。不要把整个扩展再套进一层文件夹，也不要提交自己的世界书数据。

本版本已通过 31 项自动化测试。在仅含内存测试数据的模拟酒馆页面中检查了打开、保存、撤销后再保存、单条和多条拖动、移动到最后、筛选时的移动保护、列表调宽、更新下载及未保存草稿的刷新保护。接口依据 SillyTavern 1.17.0 源码适配；尚未在用户的真实酒馆中安装或写入世界书。

```
manifest.json       酒馆扩展清单
index.js            扩展入口、按钮与酒馆缓存同步
style.css           宿主窗口样式
bridge.js           使用酒馆当前会话的世界书读写
updater.js          安装范围识别与原生扩展更新接口
editor/             图形化编辑器
tests/              不连接真实酒馆的自动化测试
```
